# =============================================================================
# 【高安全性静态文件服务器】UltraSecureHTTPServer v1.0
# =============================================================================
#
# 本程序是一个极简但高度安全的静态文件服务器，专为在受控环境中提供只读文件访问而设计。
# 它不依赖任何第三方 Web 框架（如 Flask、Django），而是直接基于 Python 标准库构建，
# 从而最大限度地减少攻击面，并实现对安全策略的完全掌控。
#
# ————————————————————————————————————————————————————————————————
# 【核心安全设计理念】
# ————————————————————————————————————————————————————————————————
# 1. **纵深防御 (Defense in Depth)**：
#    - 从网络层（IP白名单）到应用层（路径校验、文件白名单）设置多道防线。
#    - 即使某一层被绕过，后续防线仍能阻止攻击。
#
# 2. **最小权限原则**：
#    - 仅允许访问明确授权的文件（启动时扫描生成白名单）。
#    - 仅允许来自可信 IP 的连接。
#    - 仅支持 GET 方法，拒绝其他所有 HTTP 动词。
#
# 3. **主动防御与自动封禁**：
#    - 对高频请求（疑似扫描）的 IP 自动加入黑名单。
#    - 对包含危险字符（如 `..`, `;`, `$`）的请求立即拦截并记录。
#
# 4. **信息隐藏**：
#    - 所有错误页面均伪装成 Apache 服务器，隐藏真实技术栈。
#    - 统一返回 404（而非 403），避免向攻击者泄露“存在但禁止访问”的信息。
#
# 5. **资源保护**：
#    - 极短的 Socket 超时（1秒）防御 Slowloris 等慢速攻击。
#    - 固定大小的线程池防止资源耗尽。
#    - 日志文件自动轮转，防止磁盘占满。
#
# ————————————————————————————————————————————————————————————————
# 【使用说明】
# ————————————————————————————————————————————————————————————————
# 1. **目录结构要求**：
#    - 在本脚本同级目录下创建一个名为 `files` 的文件夹。
#    - 将您希望对外提供的**安全文件**放入此文件夹中。
#    - ⚠️ 注意：`.env`, `.git`, `.log`, `.py` 等敏感文件会被自动忽略。
#
# 2. **配置访问权限**：
#    - 编辑 `ALLOWED_IPS` 集合，添加您信任的客户端 IP 地址。
#    - 默认仅允许本地回环地址 (`127.0.0.1` 和 `::1`)。
#    - 如需开放给局域网设备，请添加如 `'192.168.1.100'`。
#
# 3. **启动服务器**：
#    ```bash
#    python ultra_secure_server.py
#    ```
#    - 服务器将在 `http://127.0.0.1:8080/` 启动。
#    - 访问日志将同时输出到控制台和 `logs/server.log`。
#
# 4. **访问文件**：
#    - 假设 `files/` 目录下有 `report.pdf`，则通过以下 URL 访问：
#      http://127.0.0.1:8080/report.pdf
#    - 如果存在 `files/index.html`，访问根路径 `/` 将返回该文件。
#
# 5. **安全监控**：
#    - 所有安全拦截事件（如路径遍历尝试、高频请求）都会记录到日志。
#    - 被自动封禁的 IP 会出现在日志的 `[自动封禁]` 条目中。
#
# ————————————————————————————————————————————————————————————————
# 【重要警告】
# ————————————————————————————————————————————————————————————————
# - 本服务器**绝不应**直接暴露在公网上！
# - 请务必配合防火墙、反向代理（如 Nginx）或部署在内网环境中使用。
# - 任何未在 `ALLOWED_IPS` 中的 IP 都将被静默拒绝。
